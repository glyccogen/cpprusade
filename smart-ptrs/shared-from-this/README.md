# SharedFromThis

Общая информация по задачам на умные указатели [здесь](../README.md).

В этой задаче нужно реализовать `EnableSharedFromThis`: механизм, который
позволяет получить `SharedPtr` или `WeakPtr`, имея только `this`.

Эта задача опирается на `SharedPtr` и `WeakPtr`, поэтому вместе с основными
тестами собираются тесты на обе предыдущие задачи.

Подробности ожидаемого поведения лучше смотреть в тестах.
