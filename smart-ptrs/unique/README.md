# UniquePtr

Общая информация по задачам на умные указатели [здесь](../README.md).

В этой задаче нужно реализовать `UniquePtr` --- умный указатель с уникальным
владением объектом.

Для хранения указателя и deleter'а предполагается использовать решение задачи
[`CompressedPair`](../compressed-pair/README.md).

Подробности ожидаемого поведения лучше смотреть в тестах.
