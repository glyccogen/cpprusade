# SharedPtr

Общая информация по задачам на умные указатели [здесь](../README.md).

В этой задаче нужно реализовать `SharedPtr` — умный указатель с разделяемым
владением объектом.

Отдельно требуется реализовать `makeShared`: объект и контрольный блок должны
создаваться одной аллокацией.

Подробности ожидаемого поведения лучше смотреть в тестах.
