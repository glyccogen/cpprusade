# IntrusivePtr

Общая информация по задачам на умные указатели [здесь](../README.md).

## Что это?

`IntrusivePtr` — умный указатель, похожий по семантике на `SharedPtr`, но без
возможности брать `WeakPtr` на указатель.

Реализация `IntrusivePtr` проще, чем `SharedPtr`, за счет ограничения на
пользовательский тип:

* внутри типа находится счетчик ссылок;
* есть метод `inc_ref`, увеличивающий внутренний счетчик ссылок;
* есть метод `dec_ref`, уменьшающий внутренний счетчик ссылок; при достижении
  нуля объект автоматически разрушается;
* есть метод `ref_count`, возвращающий текущее значение счетчика.

Важно, что все состояние указателя находится в объекте, на который он указывает.
Это позволяет создавать корректный `IntrusivePtr` из сырого указателя.

Рядом с `IntrusivePtr` реализован удобный класс-миксин, позволяющий вставить
счетчик ссылок в любой объект, просто отнаследовавшись от него:

```cpp
class MyClassWithIntrusiveCounter : public SimpleRefCounted<MyClassWithIntrusiveCounter> {
    // ...
};
```

## Зачем это?

За счет более строгих требований на пользовательский тип и отсутствия `WeakPtr`
`IntrusivePtr` реализуется проще и эффективнее, чем `SharedPtr`.

Такая абстракция удобна для нетривиальных времен жизни объектов, например когда
объекты создаются и уничтожаются через внешний пул.
