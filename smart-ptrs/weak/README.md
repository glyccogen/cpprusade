# WeakPtr

Общая информация по задачам на умные указатели [здесь](../README.md).

В этой задаче нужно реализовать `WeakPtr` — невладеющую ссылку на объект,
которым управляет `SharedPtr`.

Эта задача опирается на `SharedPtr`, поэтому вместе с тестами `WeakPtr`
собираются и тесты на `SharedPtr`.

Подробности ожидаемого поведения лучше смотреть в тестах.
